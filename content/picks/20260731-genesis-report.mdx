### 2-3. 최종 관문을 통과한 2종목 — 그리고 R:R 탈락

ATR 5% 이하 + 정배열 + 당일 상승, 세 조건을 동시에 만족한 개별주는 **338종목 중 단 2개**였다.

#### HMM (011200) — R:R 1.55 탈락

| 항목 | 값 |
| :--- | :--- |
| 종가 | 20,950원 (+1.45%) |
| ATR(14) | 954원 (**4.56%**, 주의 등급) |
| 이동평균 | 20,950 > 20,500(5일) > 20,121(20일) > 19,877(60일) — **정배열 ✅** |
| 외국인 | **4거래일 연속 순매수** (134,164 → 352,000 → 471,317 → **412,067주**) |
| 기관 | **-236,112주 (오늘 순매도 전환)** |
| 거래량 | 148.7만주 (전일 181.1만주 대비 **감소**) |

- **손절가**: 기술적 지지선(20일선 20,121)과 ATR×1.5 기준(20,950 - 1,431 = 19,519) 중 **더 넓은 쪽 → 19,500원 (-6.92%)**
- **목표가**: 60일 고가 저항 **23,200원 (+10.74%)**
- **R:R = 10.74 ÷ 6.92 = 1.55** → **2:1 미달, 탈락**

> 외국인 4일 연속 순매수는 좋은 신호다. 그러나 **오늘 기관이 순매도로 돌아섰고, 거래량이 줄었다.** 지수가 17.91% 오른 날 거래량이 감소했다는 것은 이 종목에 오늘의 자금이 오지 않았다는 뜻이다.

| 항목 | 값 |
| :--- | :--- |
| 종가 | 33,600원 (+2.75%) |
| ATR(14) | 1,612원 (**4.80%**, 주의 등급) |
| 이동평균 | 33,600 > 32,640(5일) > 31,350(20일) > 30,888(60일) — **정배열 ✅** |

| 기관 | **-178,227주 (3일 연속 순매수 후 오늘 순매도 전환)** |

> **어제 리포트의 1순위 종목이 우리금융지주였다.** 당시 제시한 진입 전제조건은 **"33,950원 저항 돌파"** 였다.
>
> 오늘 우리금융은 장중 고가 **33,850원**까지 올라 저항선을 **100원 남기고 되밀렸고, 종가는 33,600원**이다. **전제조건은 여전히 충족되지 않았다.** 어제 조건을 걸어둔 것이 그대로 유효하게 작동했다.
>
> 33,850원은 20일 고가이자 60일 고가다. 이 가격을 종가로 넘어서기 전까지 신규 진입 근거는 없다.

다음 두 가지가 **동시에** 충족되면 종목 발굴을 재개한다.

1. **후보 종목 평균 ATR/주가가 5% 이하**로 내려올 것 — 현재 시장 91.1%가 발간금지 등급
2. **R:R 2:1 이상 종목이 최소 2개** 확보될 것

> ATR(14)은 14거래일 평활 평균이므로, 오늘 같은 극단적 변동성이 지표에서 빠지는 데는 **최소 2~3주**가 걸린다. 8월 초중순까지는 선정 종목 수가 평소보다 적을 수 있다. **이것은 시스템의 오류가 아니라 설계된 동작이다.**
